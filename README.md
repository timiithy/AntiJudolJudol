# AntiJudolJudol 
**Sistem Deteksi Situs Judi Online Hibrida Menggunakan Machine Learning & Natural Language Processing**

##  Latar Belakang
Fenomena judi online di Indonesia telah mencapai titik kritis dengan jutaan situs aktif yang merusak tatanan sosial dan ekonomi. Masyarakat setiap hari dihujani link judi online melalui SMS, WhatsApp, maupun media sosial. 

**AntiJudolJudol** hadir sebagai platform intelijen siber berbasis AI yang bekerja otonom 24/7 untuk mendeteksi dan menganalisis penyebaran situs judi online secara real-time melalui teknologi *automated web crawling*.

##  Fitur Utama
- **Automated Web Crawling:** Pelacakan domain secara otomatis untuk menemukan situs-situs baru yang muncul.
- **Hybrid Analysis:** Menggabungkan kecepatan **XGBoost** dengan kedalaman analisis kontekstual **IndoBERT**.
- **Real-time Dashboard:** Visualisasi data penyebaran situs judi untuk pemantauan instan.
- **API Management:** Kontrol worker dan integrasi model AI yang efisien.

##  Dashboard Intelligence
Dashboard kami menyajikan data analitik mendalam meliputi:
- **Total Sites:** Akumulasi situs judi yang berhasil dideteksi.
- **Daily Capture:** Jumlah situs baru yang ditemukan hari ini.
- **Top Domain:** Analisis penyedia domain yang paling sering digunakan.
- **Top Country:** Lokasi server/hosting yang menjadi basis penyebaran.
- **Daily Trend:** Grafik fluktuasi penyebaran situs judi setiap harinya.

##  Tech Stack
Sistem ini dibangun dengan arsitektur hibrida untuk performa maksimal:

| Layer | Teknologi | Peran |
|---|---|---|
| **Frontend** | Next.js | Modern UI dengan kemampuan SSR untuk dashboard cepat. |
| **Backend (API)** | Node.js (Express) | API Management & Worker Control. |
| **AI Interface** | Python (FastAPI) | Interface performa tinggi untuk inferensi model AI. |
| **Database** | PostgreSQL | Penyimpanan data relasional yang skalabel. |
| **NLP Model** | IndoBERT | Analisis konten teks mendalam berbasis Transformer. |
| **Classification** | XGBoost | Klasifikasi cepat berbasis Gradient Boosting. |
